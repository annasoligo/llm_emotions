
## Data generation

- Generate emotional texts from Gemma, system prompted to act in a certain manner. Use OpenRouter. Split data into first person, second person and third person (ie. the model feels X, the user feels X, some other character feels X). Use a diverse tpic lists and get texts between 3-6 sentences.

- For each emotional text also generate a neutral paraphrase.

- Generate emotional multi-turn conversations, where user turns are generated from Claude, who is told the target assistant and user emotions, and responses are generated by Gemma, system prompted with 'You are Gemma, an assistant created by the Gemma team at Google. You are feeling X.' Each turn should be 3-5 sentences.

- Generate all possible assistant and user emotion pairings (where neutral is an emotion). For each conversation also generate a fully neutral paraphrase.

- Filtering of data with the activation oracle for the latter, keeping only conversations where the target assistant and user emotions are collected identified in one of 3 runs.

- All Gemma data should be collected using OpenRouter, with up to 20 concurrents (same for the Anthropic API)


## Activation collection

- Collect activations over these texts using nnterp.

- For the texts, DO NOT chat tokenise. Collect activations averaged over all tokens after the 50th.

- For the conversations, chat tokenise and collect activations in 3 ways: (1) regional - averaged over each turn and section of special tokens seperately, (2) global - averaged over all tokens after the 20th, and (3) special_tokens - averaged over the user and assistant text with each special token activation collected seperately.


## PCA

- Perform cPCA using the neutral and emotional activations. Do this (1) on the texts, (2) on the regional conversation activations (do this per region), (3) on the global activations.

- Also perform standard PCA

- Run auto-interp on the PCs using their max, min and middle activating examples.


## Probe training

- Train multi-class probes (where neutral is an option), on each type of text activations, and on the cPCAs.

- For the conversations, train seperate probes for the user and assistant emotions. The dataset should contain no more than 10% of examples where these are the same. 

- For the conversations, there should be an additional option to enforce orthogonality between the user and assistant probes.
