# Research Tools Documentation

Organized documentation for the research-tools repository.

## Directory Structure

### 📐 architecture/
**System design and architectural documentation**
- `output_structure.md` - Output directory organization and conventions
- `probe_pipeline.md` - Probe application pipeline architecture and audit

### 📊 data/
**Data-related documentation and guides**

### 📚 historical/
**Completed refactorings and migrations**
- `alpaca_standardization.md` - Alpaca baseline standardization completion
- `normalization_refactor.md` - Probe normalization refactoring completion
- `reorganization.md` - Repository reorganization completion

### 💡 proposals/
**Feature proposals and improvement plans**
- `emotion_analysis_improvements.md` - Dashboard and analysis improvements

## Navigation Tips

- **Looking for system architecture?** → See `architecture/`
- **Understanding data organization?** → See `data/`
- **Reviewing past changes?** → See `historical/`
- **Planning new features?** → See `proposals/`

## Contributing Documentation

When adding new documentation:
1. **Architecture docs** - Design decisions, system structure, technical specifications
2. **Data docs** - Dataset descriptions, baseline guides, preprocessing info
3. **Historical docs** - Completed refactorings, migration summaries (include date and commit)
4. **Proposals** - Feature ideas, improvement plans, experimental designs

Keep root-level docs minimal - most documentation should live in these subdirectories.
